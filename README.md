# OBSERVE

Static, local-only demo of what a page can read from a browser: canvas, WebGL, screen, CPU/memory hints, fonts, CSS media, WebAudio, WebRTC, pointer/scroll, plus an AliExpress-style silent audio graph.

No tracking score. No fingerprint upload. No third-party analytics.

[Live on GitHub Pages](https://imano177.github.io/observe-lab/)

```
python -m http.server 8765
```

Then open `/` or a project-page subpath. Assets are relative.
